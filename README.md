# Projekt i implementacja systemu do rejestracji ambisonicznych odpowiedzi impulsowych pomieszczeń

Uruchomienie programu `sound_devices.py` pozwoli na dobranie odpowiednich ID przy wyborze urządzeń input/output w
funkcji **main()** w programie `ambisonic_ir.py`.
<pre>device_in = 1
device_out = 3</pre>
Na ten moment wartości te są ustalane statycznie, natomiast później będzie możliwość wybierania urządzeń dynamicznie poprzez
interfejs użytkownika.
